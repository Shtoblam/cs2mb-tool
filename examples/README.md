# Examples / placeholders

Эти файлы показывают ожидаемую структуру входных данных. Они **не содержат**
игровых ресурсов и не являются рабочими путями.

```text
inputs/de_example/
  de_example.nav
  entities.txt
  world_physics_physics.gltf
  world_physics_physics.bin
```

- `.nav` — навигационный граф карты.
- `entities.txt` — текстовый dump entity lump.
- `.gltf` + `.bin` — physics collision карты.

См. `inputs/README.md` и tutorial в приложении.
