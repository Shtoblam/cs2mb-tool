# CS2 Map Balance 2.1.0-alpha.2 — аудит безопасности и сборка для тестеров

Финальная alpha-сборка линии 2.1 для тестеров. Runtime-поведение совпадает с
2.1.0-alpha.1; добавлены VAC/CS2-аудит, Git-аудит, двуязычная документация и
новые визуалы.

## Результат безопасности

**Зелёный свет для локального альфа-теста.** Статический аудит не нашёл пути
взаимодействия с VAC или процессом CS2.

| Проверка | Результат |
|---|---|
| запускает CS2/Steam | нет |
| подключается к процессу | нет |
| читает/пишет память | нет |
| DLL-инъекции/хуки/оверлей | нет |
| автоматизация ввода/команды | нет |
| сеть к игре/VAC/Steam | нет |
| запись в каталог игры | нет |
| телеметрия/внешний API | нет |
| администратор/root | нет |

Приложение — локальный анализатор файлов: read-only читает VPK/nav/entity/vmdl,
пишет результаты в `artifacts/` и отдаёт viewer на `127.0.0.1`.

**Зачем папка CS2?** Только для необязательного Prepare + Generate: в map VPK
лежат nav, entity lump и `world_physics.vmdl_c`. Upload/drop не требует доступа.
`resourceinfo.exe` — read-only диагностика Valve.

**Source2Viewer-CLI** — отдельный MIT-инструмент, не входит в проект и не
скачивается автоматически. Он конвертирует уже извлечённый
`world_physics.vmdl_c` в glTF + `.bin`; в CS2 не загружается. Используйте
доверенную закреплённую сборку (тестировалась 20.1), проверяйте источник/hash,
кладите в `tools/bin/` или задавайте `S2V_CLI`.

**Не абсолютная гарантия:** Valve может изменить правила. Зелёный свет
относится к этому коду и перечисленным зависимостям, а не к любым файлам,
которые пользователь положит в `tools/bin/`.

Полная модель: [SECURITY.ru.md](../SECURITY.ru.md).

## Условия для тестеров

- обычная установка Steam, без изменения файлов игры;
- без читов, трейнеров и автоматизации матчей;
- сервер только на loopback;
- закрыть CS2 на время авто-извлечения карты;
- не распространять ресурсы Valve.

## Ограничения

- нет combat/detection/encounter и динамической силы;
- verdict — только route-time, не win-rate;
- route cards требуют стандартные callouts;
- для авто-режима нужен Source2Viewer-CLI; иначе — glTF + `.bin`;
- full clearance — Dust2/Nuke, остальные alpha-карты — skip.
