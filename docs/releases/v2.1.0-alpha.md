# CS2 Map Balance 2.1.0-alpha.1

Patch release: automatic map preparation, balance verdict, comparison and
bilingual documentation.

## Highlights

- **Prepare + Generate from installed CS2**:
  - extracts `.nav`, entity lump and `world_physics.vmdl_c`;
  - runs `resourceinfo` and Source2Viewer-CLI;
  - builds the viewer in one job.
- **Time-only balance verdict** in the library:
  - `BALANCED`;
  - `CT +Ns`;
  - `T +Ns`;
  - based on median low route time; not combat/win-rate.
- **Compare selected** maps in the library.
- **Bilingual repository**: English + Russian README and core guides.
- Dyn map title/name fixed for every generated map (no more Dust II everywhere).
- UTF-16 `resourceinfo` dumps supported.
- Maps without `Middle` no longer crash split generation.
- Persisted viewer links work after server restart.
- 49 tests.

## Run

```powershell
python app\server.py --port 8765
```

Automatic extraction needs Source2Viewer-CLI in `tools/bin/` or `S2V_CLI`.
Without it, use upload/drop.

## Known limitations

- no combat, detection/encounter or dynamic strength;
- route cards require `BombsiteA/B/Middle`;
- no alternative routes;
- no automatic Source2Viewer download;
- clearance full only on Dust2/Nuke in the alpha batch.
