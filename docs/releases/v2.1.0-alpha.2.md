# CS2 Map Balance 2.1.0-alpha.2 — Safety audit & tester build

This is the final **alpha tester build** for the 2.1 line. Runtime behavior is
the same as 2.1.0-alpha.1; this release adds the VAC/CS2 safety audit, the Git
audit, bilingual safety documentation and new visual assets.

## Safety result

**Green light for local alpha testing.** The static audit found no code path
that interacts with VAC or the CS2 process.

| Check | Result |
|---|---|
| launches CS2 or Steam | no |
| attaches to game process | no |
| reads/writes process memory | no |
| DLL injection / hooks / overlay | no |
| input automation / console commands | no |
| connects to game servers, VAC or Steam | no |
| writes into the game folder | no |
| telemetry / external API | no |
| administrator/root | no |

The app is a local file analyzer. It reads map VPK/nav/entity/vmdl files
read-only, writes results under `artifacts/`, and serves the viewer on
`127.0.0.1`.

**Why the CS2 folder?** Only the optional **Prepare + Generate** mode needs it:
the map VPK contains the nav graph, entity lump and `world_physics.vmdl_c`.
Upload/drop mode does not need folder access. `resourceinfo.exe` is Valve's
read-only diagnostic tool.

**Source2Viewer-CLI** is a separate MIT tool, not bundled and not
auto-downloaded. It converts the already-extracted `world_physics.vmdl_c` to
glTF + `.bin`; it is not loaded into CS2. Use a trusted pinned build (20.1 was
tested), verify its source/hash, and place it in `tools/bin/` or set `S2V_CLI`.

**No absolute guarantee:** Valve can change policies. The green light applies
to this code and the listed dependencies, not to arbitrary files placed in
`tools/bin/`.

## Tester conditions

- use a normal Steam installation and do not modify game files;
- do not combine the app with cheats, trainers or match automation;
- keep the local server on loopback;
- close CS2 while auto-extracting a map to avoid a locked VPK;
- use the release source archive or clone, but do not redistribute Valve
  assets.

## Known limitations

- no combat, detection/encounter or dynamic strength model;
- verdict is route-time only, not win-rate;
- route cards need standard `BombsiteA/B/Middle` callouts;
- auto extraction needs Source2Viewer-CLI; otherwise upload a glTF + `.bin`;
- full clearance was run on Dust2/Nuke; other alpha maps used skip clearance.
