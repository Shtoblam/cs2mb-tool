# CS2 Map Balance pre-alpha v1.0 — clean repository baseline

**Version:** `pre-alpha v1.0`

**Type:** fresh repository baseline, not a GitHub release

This is the initial baseline of the `cs2mb-tool` repository. The project keeps
the documented map-analysis scope and the historical 2.x release archive, while
the current application version and repository identity are updated.

- No map-analysis algorithm, movement model, collision calculation or
  simulation behavior was changed.
- The intake UI now sends a CSP response header and referrer policy in addition
  to its matching meta policies.
- Current verification covers 56 unit tests, compilation, the repository
  hygiene scan and documentation checks.

Historical 2.x release notes remain in this directory.
