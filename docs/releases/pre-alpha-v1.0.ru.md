# CS2 Map Balance pre-alpha v1.0 — чистый baseline репозитория

**Версия:** `pre-alpha v1.0`

**Тип:** исходный baseline репозитория, не GitHub release

Это исходный baseline репозитория `cs2mb-tool`. Проект сохраняет
документированный объём анализа карт и исторический архив релизов 2.x, при
этом текущая версия приложения и идентичность репозитория обновлены.

- Алгоритмы анализа карт, модель движения, расчёт коллизий и поведение
  симуляции не изменялись.
- Intake UI теперь отправляет CSP и referrer policy в HTTP-заголовках в
  дополнение к соответствующим meta policy.
- Текущая проверка включает 56 unit tests, компиляцию, repository hygiene scan
  и проверки документации.

Исторические release notes 2.x остаются в этом каталоге.
