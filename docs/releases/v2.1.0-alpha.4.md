# CS2 Map Balance 2.1.0-alpha.4

**Date:** 2026-11-20  
**Type:** maintenance / UX and security hardening

## What's new

- Cleaner local app layout with collapsible automatic-preparation and file-upload panels.
- More compact controls, calmer spacing, improved small-screen layout and clearer status hierarchy.
- Generated map viewers open in a separate browser tab/window by default. The inline preview is optional and lazy-loaded.
- Processing logs are collapsed until requested.
- The app now labels route-time numbers as preliminary estimates rather than a full match-balance result.

## Fixes and hardening

- The in-app tutorial reflects the public repository and current alpha release.
- Viewer URLs from the local map library are HTML-escaped before rendering.
- JSON endpoints reject empty, malformed, or non-object JSON bodies with a controlled 400 response.
- Generated viewer pages receive a restrictive same-origin CSP, no-referrer policy and no-store response headers.

## Scope unchanged

This update does not change nav parsing, collision checks, movement assumptions, route calculation, or the time-only balance heuristic. Enemy encounters, firefights, utility, line of sight and match outcomes are still not simulated. Validate all route-time observations in CS2.

## Verification

GitHub Actions passed: Python compilation, all 53 unit tests, and the repository hygiene scan.
