# CS2 Map Balance 2.1.0-alpha.4

**Дата:** 2026-11-20  
**Тип:** техническое обновление / интерфейс и безопасность

## Что изменилось

- Интерфейс стал компактнее: автоматическая подготовка из CS2 и загрузка файлов теперь находятся в сворачиваемых блоках.
- Обновлены отступы, состояния элементов, иерархия статусов и отображение на небольших экранах.
- Viewer по умолчанию открывается в отдельной вкладке/окне браузера. Встроенный preview можно включить по желанию; он загружается только при открытии.
- Журнал обработки свёрнут, пока он не нужен.
- В интерфейсе показатели времени маршрута обозначены как предварительные оценки, а не итоговый вывод о балансе матча.

## Исправления и усиление безопасности

- Внутренняя инструкция учитывает, что репозиторий публичный, и ссылается на актуальную alpha.
- Ссылки viewer из локальной библиотеки экранируются перед вставкой в HTML.
- JSON API корректно отклоняет пустые, некорректные и не-объектные JSON-тела с ответом 400.
- Для страниц viewer добавлены строгая same-origin CSP, запрет передачи referrer и запрет кэширования.

## Что не менялось

Алгоритмы nav parsing, collision checks, movement, расчёт маршрутов и time-only эвристика баланса не менялись. Встречи противников, перестрелки, utility, видимость и исходы матчей по-прежнему не симулируются. Проверяйте все наблюдения по времени маршрута в самой CS2.

## Проверка

GitHub Actions прошёл успешно: компиляция Python, все 53 теста unittest и проверка гигиены репозитория.
