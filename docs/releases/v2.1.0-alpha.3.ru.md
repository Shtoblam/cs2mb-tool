# CS2 Map Balance 2.1.0-alpha.3 — установка и запуск

Alpha-релиз с полным onboarding. Runtime и map pipeline не изменились по
сравнению с alpha.2.

## Установка и запуск

README и tutorial **? Установка** теперь описывают полный путь на Windows:

1. установить Python 3.13 x64 с PATH;
2. получить source ZIP приватного репозитория или клонировать проект;
3. запустить `app\server.py` на `127.0.0.1:8765`;
4. положить Source2Viewer-CLI 20.1 в `tools\bin\`;
5. собрать карту из установленной CS2 или использовать upload.

## Source2Viewer-CLI

Добавлен отдельный раздел:

- ссылка на официальный ValveResourceFormat **20.1**;
- точный Windows asset: `cli-windows-x64.zip`;
- три обязательных файла:
  - `Source2Viewer-CLI.exe`
  - `libSkiaSharp.dll`
  - `spirv-cross.dll`;
- точное место: `<PROJECT>\tools\bin\`;
- альтернативы: `S2V_CLI` и `config\paths.local.json`;
- команды проверки;
- SHA-256 проверенных артефактов 20.1;
- запрет класть файлы в CS2/Steam и коммитить их.
