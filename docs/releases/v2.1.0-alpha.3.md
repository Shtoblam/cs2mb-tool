# CS2 Map Balance 2.1.0-alpha.3 — Installation tutorial

This alpha is a **documentation and onboarding release**. Runtime behavior and
the map pipeline are unchanged from alpha.2.

## Install & run

The README and the in-app **? Установка** tutorial now cover the complete
Windows setup:

1. install Python 3.13 x64 with PATH;
2. get the private-repo source ZIP or clone the repository;
3. start `app\server.py` on `127.0.0.1:8765`;
4. place Source2Viewer-CLI 20.1 in `tools\bin\`;
5. generate a map from the installed CS2 folder, or use upload mode.

## Source2Viewer-CLI

Added a separate section with:

- official ValveResourceFormat **20.1** release link;
- the exact Windows asset: `cli-windows-x64.zip`;
- the three required files:
  - `Source2Viewer-CLI.exe`
  - `libSkiaSharp.dll`
  - `spirv-cross.dll`;
- exact destination: `<PROJECT>\tools\bin\`;
- alternatives: `S2V_CLI` and `config\paths.local.json`;
- verification commands;
- tested SHA-256 hashes for the 20.1 artifacts;
- warning not to put files in the CS2/Steam folder and not to commit them.
