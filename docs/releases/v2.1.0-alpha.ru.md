# CS2 Map Balance 2.1.0-alpha.1

Патч: автоматическая подготовка карты, verdict, сравнение и двуязычная
документация.

## Главное

- **Prepare + Generate from installed CS2**:
  - извлекает nav, entity lump и `world_physics.vmdl_c`;
  - запускает `resourceinfo` и Source2Viewer-CLI;
  - собирает viewer одним job.
- **Time-only verdict** в library: `BALANCED`, `CT +Ns`, `T +Ns`.
- **Compare selected** для нескольких карт.
- Двуязычные README и основные guides.
- Исправлено название карты во всех viewer (больше не Dust II).
- Поддержка UTF-16 entity dumps.
- Карты без `Middle` больше не падают.
- Persisted viewer links после перезапуска.
- 49 тестов.

## Запуск

```powershell
python app\server.py --port 8765
```

Для авто-режима нужен Source2Viewer-CLI в `tools/bin/` или `S2V_CLI`.

## Ограничения

- нет combat/detection/encounter;
- verdict не win-rate;
- route cards требуют стандартные callouts;
- нет alternatives;
- Source2Viewer не скачивается автоматически;
- full clearance только Dust2/Nuke в alpha-батче.
