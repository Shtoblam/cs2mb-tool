# CS2 Map Balance 2.1.0-alpha.5 — веха брендинга и сайта

**Тег:** `v2.1.0-alpha.5`

**Диапазон релиза:** `v2.1.0-alpha.4..v2.1.0-alpha.5` (11 коммитов)

**Целевой commit тега:** `3b76d6805bac59ff9a1cc251a0a13cb952d29cd8`
(только документация)

**Дата публикации:** 2026-11-21

**Тип:** веха проекта, охватывающая редизайн сайта/product presentation и
небольшую интеграцию брендинга в приложение

## Что изменилось

- Статический сайт проекта перестроен как product-presentation site
  (`index.html`, `site.css`, `site.js`, баннеры сайта).
- Обновлён GitHub Pages workflow.
- Интегрирован брендинг приложения: `app/index.html` использует локальный
  `/logo.png`, `app/server.py` добавляет route `/logo.png`, а `logo.png`
  добавлен в репозиторий.
- В `tests/test_app_ui.py` и `tests/test_server_security.py` добавлены
  regression-проверки для logo/favicon и route логотипа.
- Обновлены release-, project-state- и документационные файлы.

## Что не изменилось

- Не изменены алгоритм анализа карт, навигационный граф, расчёт коллизий,
  модель движения, сценарии симуляции или расчёт баланса.
- Объём анализа остаётся time-only route/comparison indicators; без combat,
  detection/encounter simulation и win-rate модели.
- Модель безопасности CS2 остаётся локальной и read-only, без процесса игры и
  доступа к памяти.
- `VERSION` остаётся `2.1.0-alpha.4`. Эта веха не повышала версию приложения.

## Тег и диапазон релиза

Commit, на который указывает тег, содержит только документацию. Полный диапазон
релиза — нет: в него входят интеграция брендинга, route `/logo.png` и два теста.
Не определяйте объём релиза только по целевому commit тега.

Последующие коммиты `main` после тега продолжили изменения сайта и документации;
application/analysis-код после тега не менялся.

## Проверка при публикации

В опубликованном release указано, что тесты приложения не перезапускались,
поскольку application и analysis code не менялись. Для диапазона релиза это
утверждение неточно: branding route и тесты в него входят. Эта заметка не
добавляет задним числом других проверок. Актуальные проверки репозитория — в
[STATE.md](../STATE.md) и [changelog](../../CHANGELOG.md).

## Внешнее действие

Опубликованное описание GitHub release повторяет утверждение, что local server
functionality не менялась. Это внешние метаданные; в рамках этого документационного
прохода они не изменялись. Для их обновления требуется отдельное разрешение.
