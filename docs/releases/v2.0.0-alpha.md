# CS2 Map Balance 2.0.0-alpha

Local map intake, viewer and comparison release. No combat yet.

## Install

Requirements: Windows 10/11, Python 3.13, already-extracted map resources.

```powershell
python app\server.py --port 8765
```

Open <http://127.0.0.1:8765/>. The first-run tutorial explains where the four
map files come from and how to extract them.

Full extraction guide: [docs/GETTING_FILES.md](../GETTING_FILES.md).

## Known limitations

- no detection/encounter timing;
- no combat, utility or strength prediction;
- no alternative/K-shortest routes;
- route cards require standard `BombsiteA/B/Middle` callouts;
- users must provide extracted files; automatic VPK/VRF extraction is next;
- no 3D view;
- AK range and `J+` are model estimates, not demo-calibrated.

## Security / anti-ban

The application does not launch CS2 or Steam, does not access game memory,
does not interact with anti-cheat, and does not send telemetry. It only parses
user-provided files. Do not expose the local server to the internet.
