# CS2 Map Balance v1.1.1 — примечания к релизу

**Версия приложения:** `v1.1.1`
**Версия SRI:** `1.0.0`
**Версия 3DsVW:** `1.0.0`
**Тип релиза:** patch-релиз, Windows x64

v1.1.1 — исправления корректности, санитизации путей и поддержки сборки. Новых
функций нет; существующие форматы данных, контракты координат и версии
компонентов сохранены.

## Pipeline и безопасность

- SRI читает `InteractAs` и `PhysicsTags` из отдельных исходных полей.
- Замена bundle 3DsVW выполняется транзакционно: проверенный staging-bundle
  подменяет прежний, а при ошибке сохраняется последний рабочий viewer.
- `prepare_map.py --dry-run` действительно не пишет данные, включая игровой
  сценарий приложения.
- Манифесты и сводки анализа больше не содержат абсолютных локальных путей,
  имён пользователей и путей установки Python.
- Санитизация URI sidecar не зависит от ОС: Windows drive- и UNC-пути
  сокращаются до имени файла на POSIX; удалённые URL и data URI по-прежнему
  исключаются. Проверки выхода за пределы каталога sidecar не ослаблены.

## Корректность 3DsVW

- Хранятся независимые границы collision, NAV и агрегированные границы сцены.
  Fit, Top, Isometric и сетка используют границы сцены; отступ камеры остаётся
  только визуальным.
- Идентичность материала, collision-метаданные, число треугольников и признак
  clip/sky учитываются для каждого primitive, а не для узла целиком.
- Родительские и дочерние TRS, а также явные матрицы узлов применяются ровно
  один раз для консервативных мировых границ. Контракт записан в `bounds_mode`.
- Индексированные и неиндексированные треугольники, режим primitive по
  умолчанию, неподдерживаемые режимы и некорректные ссылки node/accessor
  проверяются с контролируемыми ошибками.
- Одинаковые имена узлов сохраняют различные стабильные идентификаторы.

## Сборка и CI

- SRI использует source generation `System.Text.Json` для `PhysSummary` и
  `GltfDto`, включая вложенные типы. Именование, обработка null и пользовательский
  `Vector3JsonConverter` сохранены; trimmed Release-сборка не выдаёт IL2026.
- В CI используется версия действия настройки .NET с Node.js 24.

## Совместимость

- Windows 10/11 x64.
- Портативный Python 3.13 включён; отдельная установка не требуется.
- Версии SRI и 3DsVW остаются `1.0.0`.
- Новых зависимостей нет; координаты PHYS, routing, movement и balance не
  изменены.
- Прежние payload viewer остаются читаемыми; новые поля границ и primitive
  добавлены без нарушения совместимости.
