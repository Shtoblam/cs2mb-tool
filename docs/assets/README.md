# Asset index

The canonical CS2MB logo is the repository root `../../logo.png`. It is the
owner's original image and is not modified or replaced by a vector mark.

| Directory | Contents |
|---|---|
| `brand/` | 1280×640 social preview (SVG source and PNG export) |
| `banners/` | English and Russian README banners; both embed the original logo |
| `illustrations/` | SRI/engine, pipeline, navigation, collision and security diagrams |
| `screenshots/` | Actual current application, viewer, library, onboarding and website captures |

## Rules

- Do not add an invented CS2MB logo mark.
- Use `logo.png` for the application, website, README, favicon and social preview.
- Screenshots must come from the actual running application; do not draw or
  reconstruct an interface.
- Do not commit extracted game resources, map screenshots containing proprietary
  assets, or personal paths.
- Technical SVG files are information graphics and must remain self-contained,
  with no remote fonts or images.
