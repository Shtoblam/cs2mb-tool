Установка и запуск

Пошагово: Python → проект → Source2Viewer-CLI → запуск → карта. Если CLI нет — останется upload fallback.

00Установка: Python и проект

  1. Установите Python 3.13 x64 с python.org. Включите Add python.exe to PATH.
  2. Скачайте Source code (zip) или клонируйте репозиторий. Репозиторий публичный: можно скачать архив или клонировать его без приглашения. Распакуйте в обычную папку, например %USERPROFILE%\Documents\cs2mb-tool. Не распаковывайте в папку CS2/Steam.
  3. Откройте PowerShell в корне проекта и проверьте Python: 
    py -3.13 --version
  4. Запустите приложение: 
    py -3.13 app\server.py --port 8765
    и откройте http://127.0.0.1:8765/. PowerShell не закрывайте; Ctrl+C останавливает сервер.

pip install не нужен. Если python не найден, используйте py -3.13. Порт можно сменить: --port 8766.

01Source2Viewer-CLI: скачать и куда положить

Для авто-режима нужен CLI. Скачайте cli-windows-x64.zip со страницы релиза ValveResourceFormat 20.1 (не Source2Viewer.exe — это GUI).

Распакуйте все три файла в папку проекта:

cs2mb-tool\
  tools\
    bin\
      Source2Viewer-CLI.exe
      libSkiaSharp.dll
      spirv-cross.dll

Не кладите их в game\bin\win64, Steam или C:\Windows. Файлы игнорируются Git.

Get-ChildItem .\tools\bin
& ".\tools\bin\Source2Viewer-CLI.exe" --help
Get-FileHash ".\tools\bin\Source2Viewer-CLI.exe" -Algorithm SHA256

Приложение должно показать S2V ready. Если S2V not configured — проверьте все три файла, имя exe, запуск из корня проекта и перезапустите сервер. Альтернатива: S2V_CLI или config\paths.local.json.

Если CLI не нужен — используйте upload готового .gltf + .bin.

02Карта из установленной CS2

В Steam: Библиотека → Counter-Strike 2 → Управление → Просмотреть локальные файлы. Укажите этот корень в CS2 game folder. В нём должны быть game\csgo\maps и game\bin\win64\resourceinfo.exe.

Укажите map name, например de_mirage, и нажмите Prepare + Generate. CS2 лучше закрыть, чтобы VPK не был заблокирован.

Skip clearanceБыстрый режим ~20 s; без clearance-проверки.
Full jobВсе проверки; на Dust2 около 2.5 мин.

Приложение читает папку игры только read-only и пишет результаты в artifacts/.

03Upload-режим (если CLI/папка CS2 недоступны)

Укажите map name, перетащите четыре файла в drop zone и нажмите Generate map.

.navНавигационный граф карты: области, связи, спавны.
entity .txtDump сущностей: spawn points, callouts, bomb sites.
.gltfPhysics collision: стены, полы, клипсы. Из world_physics.
.binБинарный buffer к glTF. Без него collision не прочитается.

Команды извлечения: docs/GETTING_FILES.ru.md. Нужны все четыре файла; .bin обязателен.

04Что появится после Generate

После генерации открой viewer в отдельной вкладке или включи встроенный preview. В library доступны area/edge/floor/wall/clearance, предварительные route-time оценки и Compare selected.

Результаты лежат в artifacts/auto/<map>/<job>/. Игровые файлы не коммитятся.

05Быстрый troubleshooting

python not foundИспользуйте py -3.13; переустановите Python с PATH.
S2V not configuredВсе 3 файла в tools\bin; перезапустите сервер.
libSkiaSharp.dllРаспакуйте архив целиком, не только exe.
invalid CS2 folderНужен корень с game\csgo\maps, не папка maps.
port busy--port 8766 и откройте новый URL.
no .binЗагрузите/экспортируйте .gltf + .bin вместе.
